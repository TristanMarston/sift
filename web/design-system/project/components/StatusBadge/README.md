# StatusBadge

States a claim and where it came from: Verified, Claimed or Unknown.

Shape carries the meaning (solid, half, hollow dot) and the word confirms it. `EstTag` marks every estimated number. `StatusDot` is the dot alone.

**You provide:** `value` ("Organic cotton"), `status` (`verified`, `claimed`, `unknown`), optional `note`.

- Verified: read from the tag or a certification.
- Claimed: the seller's text.
- Unknown: shown in grey, never hidden.
