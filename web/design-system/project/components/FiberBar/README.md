# FiberBar

The fiber mix from a tag: segments fill one after another, with a labeled legend.

Colors by fiber type: plant (wheat), animal (clay), regenerated (lilac), synthetic (slate, never red). Any share the tag doesn't account for is hatched as "Not on the tag". Uncertain fibers are underlined with "Check this" and can be tapped to fix.

**You provide:** `fibers` (`[{name, pct}]`), optional `uncertain` (fiber names) and `onFix(name)`.
