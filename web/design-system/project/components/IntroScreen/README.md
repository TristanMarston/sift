# IntroScreen

The landing page: the name, the promise and one big action.

The headline sits low in `type-display`. Scan an outfit is the one cobalt button; Describe a fit and Upload a photo are the alternatives. Holding the name for 1 second loads cached results (the hidden demo fallback).

**You provide:** `onScan`, `onDescribe(text)`, `onUpload`, `onSecretHold`.
