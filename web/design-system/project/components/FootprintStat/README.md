# FootprintStat

A big estimated number that counts up when it appears: "2.1 kg CO₂ est."

Always carries an `EstTag`. Values come from the footprint table (published lifecycle averages); the label says what the number means.

**You provide:** `value`, `unit` ("kg", "L"), `label` ("CO₂ to make it new"), optional `size` (`lg` or `md`).
